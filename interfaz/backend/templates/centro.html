Instrucciones para importar el calendario

Formato del archivo

  • El archivo debe estar en formato .xlsx.
  • Debe contener una única hoja.
  • No se deben cambiar los nombres de las columnas.
  • Debe haber una fila por cada día del calendario.

Columnas

fecha Fecha del día.
centro_abierto 1 = abierto / 0 = cerrado.
es_festivo 1 = festivo / 0 = no festivo.
dia_posterior_festivo 1 = sí / 0 = no.
hora_apertura Formato HH:MM.
hora_cierre Formato HH:MM.
Importante: al importar un calendario se sustituirá el calendario actual.
